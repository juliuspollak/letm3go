# Inline map filters

The old Map Layers sheet covered the map and triggered AppleMap's dialog observer, hiding MapKit behind a snapshot. Filters now expand inside the map without a backdrop, dialog or Apply step.

React owns the saved per-account map view and the transient toolbar/category state. `mapToolbar.js` builds serializable controls for both React and UIKit. `AppleMap.jsx` sends those controls with its existing map payload; native `layersTapped` events carry action IDs back to React. UIKit buttons and horizontal UIScrollViews are direct subviews of the existing MKMapView. There is no full-map touch-intercepting overlay. Filter changes preserve the camera; explicit location requests can still refit it. Existing modal snapshot behavior remains for genuine dialogs and photo viewers.

Day navigation uses local calendar arithmetic, including DST boundaries. Selecting a day switches Off or Today to All routes; Favourites remains Favourites. This deliberately separates the Today route layer from a selected calendar day. Day filtering temporarily takes precedence over the saved rolling range. Choosing a rolling range clears the selected day. Old preferences gain only `day: null`; their range and route meanings remain unchanged. Matching tests each recorded segment separately, includes midnight-crossing activity, and excludes unobserved gaps between grouped recordings. A journey ending exactly at midnight is assigned to the preceding day.

People visibility, exclusive route layers, recorded activity choices, community trail independence, saved favourites and per-account persistence are retained. Switching map modes preserves personal filters. The obsolete sheet styles were removed while shared social-sheet and grouped-list styles remain.

Changed implementation files: `src/App.jsx`, `src/components/{MapLayers,AppleMap,JourneyMap,MtbMap}.jsx`, `src/lib/{mapLayers,mapToolbar}.js`, `src/styles.css`, and `ios/App/App/AppleMaps.swift`. Regression tests cover the toolbar, date filtering, shared control model, native bridge and app integration.
